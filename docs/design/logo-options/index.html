小机器人 Logo 候选方案

定位已从「进程管理器」调整为「Agent 主导的小型工具箱合集」。以下 6 个方向都围绕「小机器人 + 工具」展开， 每张卡片右侧是 24px / 14px 的小尺寸预览，可直接判断托盘与 favicon 下的识别度。

六个方向

建议先看小尺寸预览，再决定大图。

推荐 · 主图标

01 · 极简机器人头

深蓝灰圆角头 + 薄荷绿大圆眼 + 天线绿点。几何简单、留白充足，最像「一个 agent 本体」。

小尺寸最稳 亲近感强 工具箱语义弱
科技感

02 · 节点机器人脸

深海军蓝圆角底，方块节点与电路连线拼成机器人脸，薄荷绿方眼发光，强调 Hub / 连接。

科技感强 32px 偏碎 细节多
推荐 · 最贴定位

03 · 工具箱机器人

机器人头直接长在工具箱上，提手兼作天线，橙色眼睛与微笑。语义最完整：会使用工具的 agent。

「工具箱」语义最强 有记忆点 主色偏离 emerald
推荐 · 开发者气质

04 · 终端机器人

深色圆角屏幕脸，>_ 终端眼 + 薄荷绿描边发光。最简洁，开发者工具气质最强。

极简好缩放 开发者认同 机器人感偏弱
吉祥物

05 · 抱工具箱的小机器人

全身小机器人抱着绿色工具箱，蓝灰 + 薄荷绿描边卡通风。适合做官网吉祥物、空状态插画。

延展性最好 不适合主图标 小尺寸丢失细节
单色版

06 · 单色线稿机器人

纯绿线稿：圆角方框 + 两点眼睛 + 天线，白底。天然适合托盘 / favicon，也可以做深色主题变体。

托盘/favicon 最佳 单色易适配 做主图标偏单薄

描述文案 · 中文

AAgentHub - 本地 Agent 工具箱最贴新定位，短、可扩展；推荐用于「关于」
BAgentHub - Agent 工具箱与本地服务管家保留了托管常驻服务的实际能力
CAgentHub - 让 Agent 工具常驻运行偏价值主张，适合 README 首句
DAgentHub - 一站式 Agent 工具集强调「合集」

描述文案 · 英文 / 托盘

AAgentHub - Local agent toolbox对应中文 A，推荐 aboutDesc
BAgentHub - Agent toolbox & service supervisor对应中文 B
CAgentHub - A toolbox for AI agents更口语，适合官网

建议组合

主图标用 01 极简机器人头 或 03 工具箱机器人，按选定方向重绘为几何 SVG（保证 1024px 与 16px 都清晰）； 托盘 / favicon 用 06 单色线稿 的简化版；05 留作官网吉祥物。
文案推荐：关于页用 本地 Agent 工具箱，托盘 tooltip 用 Agent Toolbox。

候选图为概念草图，最终会以矢量 SVG 重绘后导出 PNG / ICO / ICNS。
